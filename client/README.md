# Inventory Management Dashboard

Full-stack inventory management system built for merchants.

## Features

- CRUD operations on products
- Color-coded stock status (Green / Yellow / Red)
- Dashboard with key analytics (total products, inventory value, low/out of stock counts)
- Low stock alerts section
- Search by name/SKU
- Filter by stock status
- Sort by multiple fields
- Form validation & user-friendly error messages

## Tech Stack

- **Frontend**: React, Vite, React Router
- **Backend**: Node.js, Express
- **Storage**: In-memory (array)
- **API**: REST
